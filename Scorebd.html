Mini Project

About PowerPlay

Cricket Scoreboard Management System — a college mini project.

Objective

PowerPlay is a web application that lets a scorer record every player's runs during a match, identify the highest scorer, and generate team statistics automatically — all without a backend or database.

Core Concept: Linear List (Array)

Every player is stored as an object inside a single JavaScript array — the classic Linear List data structure. Adding a player pushes a record to the array, editing updates a record in place, deleting splices it out, and finding the highest scorer performs a linear scan across the array to locate the maximum value. Sorting rearranges the array itself, and the table, charts, and statistics all re-render directly from it.

Core Features

  • Add, edit, delete and reset player records
  • Automatic Player of the Match detection with row highlighting
  • Live team statistics: total runs, average, highest/lowest score, boundaries, strike rate
  • Search by name and sort by name or runs
  • Bar chart and pie chart visualisation using Chart.js
  • Dark mode and fully responsive, stadium-inspired design

Built With

HTML5 CSS3 JavaScript (ES6) Chart.js Arrays / Linear List

How Scoring Works

1. Enter a player's name and runs (balls faced and boundaries are optional).
2. Click Add Player — the record is pushed into the players array.
3. Use Find Highest Scorer to scan the array and crown the Player of the Match.
4. Visit Team Statistics to see totals, averages and charts recomputed live.

Note

Scores are held in memory for the current session (matching the array-based mini-project brief), so refreshing the page starts a new innings.
